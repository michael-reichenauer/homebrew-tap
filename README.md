# Homebrew tap for gmd

[gmd](https://github.com/michael-reichenauer/gmd) is a Git client for the terminal that shows only the branches you choose.

    brew install michael-reichenauer/tap/gmd

For macOS on Apple Silicon, and Linux (x64 and arm64). Update with `brew update && brew upgrade gmd`.
gmd's release workflow writes `Formula/gmd.rb` for every release, so edits made here are overwritten.
